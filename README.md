# Voluntary social confinement in disease spreading: multiple waves and optimal timing of non-pharmaceutical interventions

Code and data to reproduce the numerical results and figures of the paper (submitted to *J. R. Soc. Interface*) on the SIRC model
(Susceptible–Infected–Recovered–Confined), by F. Maresca Urioste, H. Romero and F. Vazquez.

All results come from numerical integration of the model equations; no empirical data are used.

## Contents

```
code/
├── figures_sirc_ms_python.ipynb         notebook that regenerates Figs. 2–7 and S1–S3
├── requirements.txt                     Python dependencies
├── compute_fig6_data.jl                 Julia script that computes the data of Fig. 6
├── Project.toml, Manifest.toml          Julia environment
├── data_fig_6/fig6_step1_panel1..6.csv  output of compute_fig6_data.jl (six 250 × 251 matrices;
│                                        rows τ = 1..250, columns t_ini = 0..250)
└── splitting/                           supplementary analysis of two-pulse ("split") campaigns
    ├── bang_bang_check_split_tau_v2.jl  Julia sweep over τ, α/η, fraction f and gap
    ├── split_summary.csv                summary of the sweep (160 cases)
    └── verify_tau50.py / .csv           independent Python check of the τ = 50 case
```

Fig. 1 (schematic of the model) and Supplementary Fig. S4 (schematic of the two-pulse campaign) are drawings made separately and are not generated by the code.

## Reproducing the figures

1. **Python** (`numpy`, `scipy`, `matplotlib >= 3.7`; see `code/requirements.txt`):

   ```
   pip install -r code/requirements.txt
   cd code && jupyter notebook figures_sirc_ms_python.ipynb
   ```

   Running the notebook takes a few minutes and writes the figures (PDF and PNG) to a `figures/` folder created next to `code/`.
   Fig. 6 is read from `code/data_fig_6/`; the notebook can also recompute it (optional: hours at full resolution).

2. **Julia** (only to recompute the data of Fig. 6). From `code/`:

   ```
   julia --project=. -t auto compute_fig6_data.jl
   ```

   It writes `data_fig_6/fig6_step1_panel{1..6}.csv` (about 3.8·10⁵ integrations, Tsit5, `reltol = 1e-8`).
   Existing files are skipped; delete them to recompute.
   The provided CSVs agree with the Python integration of the same model to better than 1e-7 (checked on random entries).

3. **Two-pulse analysis** (Supplementary material). From `code/`; usage and options are described at the top of the script:

   ```
   julia --project=. -t 10 splitting/bang_bang_check_split_tau_v2.jl validate   # fast check (τ = 50)
   julia --project=. -t 30 splitting/bang_bang_check_split_tau_v2.jl            # full sweep (long)
   ```

   The results of the full sweep used in the paper are summarised in `code/splitting/split_summary.csv`.
   The check for τ = 50 can be compared with `code/splitting/verify_tau50.csv` (independent Python implementation, `verify_tau50.py`).

## Parameters

β = 0.2, γ = 0.1, ω = 0.025, ρ_i(0) = 10⁻⁶ (unless stated in each figure); campaign duration τ = 50 and deadline T = 250.
